# Authorized path and acceptance budget

The user delegated selection of the path, application scope and acceptance budgets on 17 September 2026. `ACCEPTANCE_BUDGETS.json` freezes those choices before the new measurements. This is project authorization, not an independent review signature.

The immediate deliverable is a GEMINI-only research branch for reproducible regional auroral-response and numerical-method experiments. The primary workload is the archived 2013 mini2dns_fang/mini3d_fang problem, with fixed Cartesian grid, standard energy, electrostatic potential, frozen empirical neutral background and complete precipitation/electric drivers. Test 1/2 MPI ranks on one Linux node in real64. Keep all nine historical reference problems as regression gates.

Stage A closes implementable engineering deficiencies: required forcing schemas, atomic publication, complete state for the admitted restart mode, transport accounting, numerical convergence and reproducible local workload measurements. Stage B implements and validates modern geomagnetic geometry and matched-regime independent physics evidence. Stage C admits observations/assimilation, surrogate/UQ and model integration only when their scientific prerequisites pass. Physical control is excluded from this research path under the latest scope authorization.

All original R01-R18 obligations remain traceable. A successful Stage A is not completion of Stage B or C. Dates are deliberately historical for the numerical benchmark; no year guard is relaxed to claim 2026 production support. New physical targets are research requirements, not accuracy claims. Restart and balance budgets are roundoff-based and must not be loosened to fit the previous residuals.
