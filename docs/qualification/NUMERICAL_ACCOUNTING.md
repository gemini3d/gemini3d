# Native numerical accounting

Enable `GEMINI_NUMERICAL_AUDIT=1` for diagnostics. Normal solver arithmetic is unchanged: face-flux output is optional and integrals are computed separately. The research matrix enables this option and retains the CSV records.

The native split-advection routine now returns the exact time-integrated, metric-weighted interface flux used by the finite-volume update. Every ion-density, parallel-momentum and all-seven-species internal-energy sweep records before/after integrals, the directly accumulated state increment, outward transport, local end-face contributions and a scale. Ghost and null cells are excluded; physical-to-null interfaces remain part of the control-volume boundary. Singleton axes perform no advection and return zero flux. Curved perpendicular momentum sweeps use the solver's covariant h1 weighting; they must not be represented as Cartesian physical momentum without a basis/metric conversion. The admitted Cartesian benchmarks avoid that ambiguity.

`check_transport.py` independently recomputes residuals from the emitted increments and fluxes. When given the MPI layout, it matches common stage times, pairs internal faces with opposite outward signs and computes the global external/null-boundary residual. Each internal pair is counted once. A missing rank, missing species/axis, duplicate stage or nonfinite value cannot pass. The present pairing contract is the nonperiodic decomposition used by the research benchmarks.

The whole-step continuity ledger records six ion equations, using actual physical volumes h1*h2*h3*dx1i*dx2i*dx3i. It accumulates the **applied** ETD chemistry/ionization increment, not an endpoint rate multiplied by dt. Density-floor and cleanup increments are a separate term. The residual is delta-number minus applied source plus outward transport minus cleanup. Multiplication by each fixed species mass gives the same normalized species-mass balance. Electron quasi-neutrality is measured separately. The native deliberate-floor test excludes a null cell and ghost storage and checks the exact known addition. The source-free periodic and curved known-boundary advection tests check conservation and three-level convergence.

These are numerical accounting statements. Recording the applied source does not validate a reaction coefficient. All individual chemistry/collision/ionization contributions, momentum source/work terms, thermal diffusion boundary fluxes, temperature-floor energy, total kinetic/internal energy exchange and full coupled-PDE grid/time convergence still belong to R04. The reference comparisons and operator refinement tests do not replace those obligations. Geometry validation and independent observational physics validation remain separate.
